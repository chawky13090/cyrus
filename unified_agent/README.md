# Unified AI Agent - MVP

This project aims to build a unified AI agent that combines chat functionalities with NetOps tools.

## MVP Scope
- Centralized chat interface (React frontend, Python Flask backend with Ollama).
- Persistent conversation memory (ChromaDB).
- Integration of Nmap (network scan) and SSH (command execution) tools.
- Basic security (authentication for UI) and comprehensive logging.
- Installer script for setup.

## Future Vision
This MVP is the first step towards a more advanced AI agent with capabilities for continuous learning, broader tool integration, and enhanced cognitive features.
